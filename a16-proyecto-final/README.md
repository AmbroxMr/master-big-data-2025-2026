# Proyecto Final

**Duración:** 3 sesiones de 3 horas

---

## ¿En qué consiste?

Durante las próximas tres clases vais a construir un proyecto propio de principio a fin. No hay un guion paso a paso: la idea, el stack y la arquitectura son vuestra decisión. El objetivo es que os enfrentéis a las mismas preguntas que tendréis en el trabajo: ¿qué tecnologías elijo? ¿cómo estructuro esto? Al final del proyecto, tendréis un sistema funcionando que podréis mostrar en entrevistas y un repositorio de código público en GitHub. *Hacedme caso, es algo que os va a servir y suelen ser muy valoradas.*

Cada carpeta de este directorio corresponde a un campo del mundo real. Dentro encontraréis 3-4 fichas de proyecto, una por idea. Elegid la que más os enganche.

## Campos disponibles

| Carpeta | Perfil profesional |
|---|---|
| `data-engineering/` | Data Engineer - pipelines, ingesta, transformación |
| `ml-engineering/` | ML Engineer - detección de patrones, analítica avanzada |
| `backend-product/` | Backend / Product Engineer - sistemas de negocio, APIs |
| `devops-platform/` | DevOps / Platform Engineer - observabilidad, infraestructura |

## Cómo elegir

1. Leed las fichas del campo que más os interese
2. Elegid una idea que podáis tener funcionando en 9 horas
3. Proponed el stack y comentadlo con el profesor antes de empezar
4. Si tenéis una idea propia que encaje en alguno de estos campos, también es válida
